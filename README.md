# Chrome Extension with TypeScript

This is a plain and simple Chrome Extension Manifest v3 project, configured with TypeScript and Vite.

## Quick start

By using [degit](https://github.com/Rich-Harris/degit), you can scaffold a new project using this template.

`npx degit kinnnine/chrome-extension-ts-vite-template my-extension`

Finally, install required packages using your package manager of choice, it can be `npm`, `pnpm` or even `bun`.
